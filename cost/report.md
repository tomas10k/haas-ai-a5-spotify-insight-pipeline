## 3. Controls

* Spend cap: **$45.00**, enforced by one shared ledger that reserves worst case cost before every call and stops admitting work at the cap (progress is saved).
* Output token cap (Haiku calls): 300. Jev output is free and has no output cap.
* Maximum workers: 8; maximum requests per second: 20.
* Haiku fallback fraction cap: 1% of processed texts. Invalid output: one retry then quarantine. Transient errors: up to 4 attempts with backoff and jitter, each logged.
* Decision: refresh this projection after 500 and 10,000 reviews, then start the full run only if the conservative scenario stays under the cap.
